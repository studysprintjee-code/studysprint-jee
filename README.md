## S3 file storage

Chapter PDF links are configured in `storage-config.js`. Upload your files to S3, then set `baseUrl` to the public S3 or CloudFront URL and change each file value to its S3 object key.

Example:

```js
window.STUDY_SPRINT_STORAGE = {
	baseUrl: "https://studysprint-assets.s3.ap-south-1.amazonaws.com",
	files: {
		physics: {
			"Units and Measurements": "physics/unit-and-dimensions.pdf"
		}
	}
};
```

Do not put AWS access keys or secret keys in this project. The browser only needs public file URLs or signed URLs generated by a secure backend.
